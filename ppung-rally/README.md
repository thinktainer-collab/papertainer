# 뿡뿡 랠리

방귀 부스트로 달리는 오프로드 레이싱 게임 기획과 시안 모음.

| 파일 | 내용 |
|---|---|
| `prototype.html` | 플레이 가능한 웹 프로토타입 (3/4 시점, 언덕·점프, 코스 3개, 업그레이드) |
| `concepts/v1-trucks-2d.html` | 차량 시안 v1: 트럭 6종 2D 일러스트와 실루엣 테스트 |
| `concepts/v1-trucks-3d.html` | 차량 시안 v1: 같은 6종의 3D 쇼룸 |
| `concepts/v2-duck-cat-racers-3d.html` | 캐릭터 시안 v2: 머리 큰 오리 4종·고양이 4종과 생활용품 탈것 3D 쇼룸 |
