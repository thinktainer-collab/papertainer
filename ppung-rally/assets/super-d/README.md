# 슈퍼 D 제트보드 (SUPER-D Jetboard)

뿡뿡 랠리의 3D 탈것 중 가장 완성도가 높은 시안. 디자이너 연필 스케치 "Flipper-CAR with MAD-duck"에서 출발했어요.

- 성난 오리가 버킷 시트에 앉아 날개로 핸들을 잡고 운전
- 킥테일 스케이트보드 차체 (검은 그립 테이프, 나무 단면, 글씨 없음)
- 높은 받침대와 긴 축에 단 오프로드 돌기 타이어
- 뒤쪽 받침대 위 제트 엔진 (흡입 팬, 빨간 띠, 노즐)

## 파일

| 파일 | 내용 |
|---|---|

| `super-d-white.glb` | 흰 성난 오리 · 보라 테두리 · 노랑 휠 |
| `preview-*.png` | 미리보기 (도색별 3/4 시점, 옆, 위) |
| `../../concepts/v4-super-d/index.html` | 원본 쇼룸 페이지: 동작(꽉! 부스트 1.8초, 점프, 질주)과 모델을 만드는 코드 |

## 규격

- 형식: glTF 2.0 바이너리(GLB), 텍스처 없이 재질 색상만 사용
- 좌표: Y 위, **+Z가 앞**(Kenney 차량 모델과 같은 방향), 바닥이 y = 0
- 크기: 폭 2.6 × 높이 3.6 × 길이 6.0 (Kenney 트럭의 약 2배. 게임에 넣을 때는 0.5배로 줄이면 트럭과 비슷해요)
- 애니메이션은 들어 있지 않아요. 움직이는 부분은 쇼룸 페이지 코드에서 따로 돌려요(바퀴, 제트 팬, 오리 머리, 아래 부리).
